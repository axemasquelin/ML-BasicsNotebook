# ML-BasicsNotebook
The intent of this repository is to review machine learning (ML) basic concepts and methodology. The goal is to explore the math, statistics, and algorithms that form the foundation of ML. Through this explorations, I aim to develop further intuition about simple ML approaches. Some deep learning topics may be covered in this repository but will be limited. 

Overall, I hope to develop small set of material that may be useful to future students, visiting researchers, and graduate students were I to become a professor. If anything, this might help me jump the gap back into industry.
